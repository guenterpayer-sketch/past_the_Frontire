# Spielstände des Nutzers

Kopien echter Spielstände zum Prüfen (Balancing, Charakterwerte, Fehlersuche). Nur lesen, nicht vom Spiel benutzt.

- Herkunft: Godot-Benutzerordner (Editor: Projekt → Benutzerdatenordner öffnen), unter Windows meist `%APPDATA%\Godot\app_userdata\Past the Frontire\`.
- `saves/slot_N.json` = Spielstand-Slot, `saves/auto.json` = Auto-Spielstand, `crew.json` und `roster.json` = laufender Stand.
- Bitte einen Unterordner mit Datum anlegen, z. B. `spielstaende/2026-10-24/`.
- Liegt bewusst außerhalb von `godot/`, damit die Dateien nicht ins Spiel exportiert werden.
